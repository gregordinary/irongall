# NIST CAVP Secure Hash Standard test vectors

The byte-oriented response files of the Cryptographic Algorithm Validation
Program's Secure Hash Algorithm Validation System, for SHA-1, SHA2-224,
SHA2-256, SHA2-384 and SHA2-512: the short-message, long-message and Monte
Carlo tests of each. The files are unmodified, including their CRLF line
endings.

- Source: <https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/shs/shabytetestvectors.zip>
- Retrieved: 2026-10-27
- Archive SHA2-256: `929ef80b7b3418aca026643f6f248815913b60e01741a44bba9e118067f4c9b8`

The archive's SHA-512/224 and SHA-512/256 files and the Monte Carlo
intermediate-value files are not included.

The Monte Carlo procedure the `*Monte.rsp` files answer is in section 6.4 of
*The Secure Hash Algorithm Validation System (SHAVS)*, NIST, 2012.
